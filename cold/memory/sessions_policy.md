# Локальные отчёты сессий

Отчёт создаётся только когда он полезен для проекта, handoff или проверки
артефакта. Он хранится **локально** в папке проекта либо в локальном состоянии
Codex.

Отчёты с consumer-устройств автоматически **не отправляются** на hub, GitHub
или внешний сервер и не являются условием получения обновлений базы.

Минимальный отчёт содержит:

- цель и фактический результат;
- изменённые файлы;
- выполненные проверки и их вывод;
- честные PASS, NOT PASS и BLOCKED;
- безопасный следующий шаг и способ rollback.

Секреты, auth-state и содержимое чужих рабочих папок в отчёт не включаются.
