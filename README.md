# OpenCode Base

Reserved clean-history repository for a future provider-neutral OpenCode base.

It will use native OpenCode configuration and remain independent of a specific
model provider. GPT may be selected through OpenCode configuration. Kimi is not
a standalone target and no Kimi-specific base is planned.

Current verdict: `FULL_RELEASE_OPENCODE: NOT_PASS`.

No `.claude` runtime, converted Claude hooks, or shared live component
repository will be used.
